# Security Policy

OopsieFS is a student prototype and should not be treated as a backup, security,
or access-control product.

## Supported Versions

Only the latest `main` branch is maintained.

## Reporting a Vulnerability

Open a GitHub issue with:

- the affected feature,
- steps to reproduce,
- expected behavior,
- actual behavior, and
- your Linux distribution/version.

Do not include private files, secrets, or personal data in reports.

## Transfer Safety

LAN transfer is intended for trusted local networks. Receiver codes expire, but
the current prototype does not provide end-to-end encryption or authentication
beyond the short transfer code.
